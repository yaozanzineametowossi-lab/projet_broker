# projet_broker

Un broker en trading est un intermédiaire agréé qui exécute vos ordres d’achat et de
vente sur les marchés financiers. Il sert de passerelle entre vous et les places boursières, tout
en fournissant parfois des outils, des données et des services supplémentaires.
Dans notre exemple, nous simulons directement l’achat et la vente via cet intermédiaire
comme s' il possédait directement les actifs.
Ce projet aura pour objectif de mettre en pratique les concepts de programmation
réseau, de gestion des connexions clients-serveur, et de communication asynchrone.
